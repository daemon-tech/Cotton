# Cotton

**The farmer's way to get string: grow it.**

Cotton adds one simple crop to vanilla farming. Break grass to find cotton seeds, plant them on farmland, and harvest cotton balls you can turn into string. You won't have to fight spiders for wool, bows, fishing rods or leads anymore.

## Features

- **Cotton Seeds** sometimes drop from short grass, just like wheat seeds
- **Cotton Plant**: an 8-stage crop that grows like wheat (bone meal works)
- **Cotton Ball**: drops from mature plants, along with extra seeds (Fortune adds more seeds)
- **Recipe:** 1 Cotton Ball → 1 String (shapeless)
- Its own creative tab

## Compatibility

- Fabric, with **Fabric API** required
- Works on both client and dedicated servers (install on both)
- Lightweight, with no config and no extra dependencies
